# AI agents topic pages: source

Source for the five topic pages under `/ai-agents/`:
`langgraph-agents`, `aws-bedrock-agents`, `voice-agents`, `ai-avatars` and `n8n-automation`.

The pages are generated by the shared renderer in `_tools/audio-pages/render_audio.py`.
Each JSON sets `"practice": "ai-agents"`, which picks the breadcrumb, colours and form field.
Don't hand-edit the page HTML. Edit the JSON here and rebuild from the repository root:

```bash
python3 _tools/audio-pages/render_audio.py . _tools/agents-pages/content/*.json
```

The content rules in `_tools/audio-pages/README.md` apply here too.
Client work is described generically. The avatar and voice assistant is "a healthcare app, currently in development": don't name the client.
A new topic page also needs a card in the `#topics` section of `ai-agents/index.html`, a share card in `_tools/share-images/make_cards.py`, and entries in `sitemap.xml` and `llms.txt`.
