# Prediction topic pages: source

Source for the three topic pages under `/predictive-intelligence/`:
`demand-forecasting`, `churn-prediction` and `causal-inference`.

The pages are generated by the shared renderer in `_tools/audio-pages/render_audio.py`.
Each JSON sets `"practice": "predictive-intelligence"`, plus `cta_href`, `nav_cta` and a `contact` block
so the pages carry the "Book a 30-minute forecasting review" CTA. Don't hand-edit the page HTML.
Rebuild from the repository root:

```bash
python3 _tools/prediction-pages/figs_prediction.py
python3 _tools/audio-pages/render_audio.py . _tools/prediction-pages/content/*.json
python3 _tools/share-images/make_cards.py og/demand-forecasting.png og/churn-prediction.png og/causal-inference.png
```

The figures land in `_tools/audio-pages/figures/` (prefix `pred-`), where the renderer reads them.
The content rules in `_tools/audio-pages/README.md` apply here too. Client proof only as the site already states it.
A new topic page also needs a card in the `#topics` section of `predictive-intelligence/index.html`, and entries in `sitemap.xml` and `llms.txt`.
