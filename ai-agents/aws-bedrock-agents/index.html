Before we start

Good questions. Straight answers.

Does our data leave our AWS account when using Bedrock?

Bedrock runs models within AWS, and you choose the regions. Data handling depends on the model provider and your configuration; we document which services, regions and logs each request touches before go-live.

Bedrock Agents, AgentCore or our own code?

Managed agents are quickest for standard tool-calling assistants. AgentCore suits teams that want their own agent code with a managed runtime. Fully custom code on Lambda or containers gives the most control. We often prototype with one and keep the option to move.

Can the agent answer phone calls?

Yes. Amazon Connect can route calls to the agent through streaming speech services, with transfer to a person when needed. We measure end-to-end delay on real phone audio, which is narrower-band than web audio.

Does it support Hebrew?

Amazon Transcribe supports Hebrew streaming transcription and Bedrock models handle Hebrew text. Speech output in Hebrew usually needs a voice from another provider, which we connect alongside AWS.

How do you control cost for a public-facing agent?

Rate limits per user and session, short sessions, caps on tokens and tool calls per turn, a bot check before expensive steps, and a budget alarm that turns the endpoint off at a fixed monthly amount.
